Панель владельца

Ставки, статусы и зоны доставки для каждой машины.

Telegram для заявок

Клиент откроет чат с этим аккаунтом, куда подставится готовый текст заявки.

Можно вставить @username или ссылку вида t.me/username.

Код доступа

Код для входа в панель. Сохранится в data.json вместе с остальными настройками.

Только цифры, от 4 до 12. Не используйте важный пароль.

Техника и условия

Для каждой машины — ставка, минимальная смена, статус и три зоны доставки. Изменения сохраняются в панели.

Публикация на сайт

Клиенты видят цены из файла data.json в корне сайта. Скачайте файл с изменениями и замените им старый на хостинге.

Есть неопубликованные изменения — клиенты пока видят старые цены.

После замены файла нажмите «Проверить на сайте» — панель сверит данные с опубликованными.
